## Screenshot Rules

- For Azure Portal procedure documents, screenshots must match the exact step being described.
- Never use a resource `Overview` page screenshot as a substitute for a creation wizard step.
- Before accepting a screenshot, verify the page title and the visible controls match the intended step, such as `Basics`, `Networking`, `Security`, `Additional settings`, or `Review + Create`.
- When a screenshot is captured for a multi-step wizard, inspect the saved image immediately to confirm it is not a stale tab, wrong blade, or previously opened resource page.
- If the screenshot does not clearly show the key field or control for that step, retake it instead of reusing a similar-looking image.
