# 3C91 回收系統業務邏輯 (BUSINESS_LOGIC.md)

## 1. 回收計價引擎
- **輸入參數**: 品牌、型號、螢幕狀況、外觀等級、電池循環次數。
- **邏輯**: 串接後端計價 API，根據當前市場行情回傳動態報價。

## 2. 訂單狀態流轉
- `PENDING`: 客戶提交申請。
- `PICKUP`: 安排取件。
- `INSPECTION`: 工程師檢測中（此階段可能會更新報價）。
- `COMPLETED`: 匯款完成並關閉訂單。

## 3. 資料來源統計
- 基於數據儀表板的統計條件，需定期盤查資料庫中 `orders` 與 `quotes` 表的關聯性。
