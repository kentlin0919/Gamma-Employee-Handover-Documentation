# 03-recycling-3c91 (3C91 回收專案交接文件)

## 1. 專案概述
本專案為 3C91 回收系統，主要負責 3C 產品的回收流程自動化、訂單管理與計價邏輯。

## 2. 技術棧
- **Backend**: [請補全，如：Python/Django]
- **Frontend**: [請補全，如：Vue/React]
- **Database**: PostgreSQL (存儲回收訂單與產品規格)

## 3. 核心模組
- **回收計價邏輯**: 根據產品型號與機況自動計算回收金額。
- **訂單管理**: 處理客戶預約回收流程。
- **串接介面**: 外部 API 串接。

## 4. 運行環境
- 啟動方式：`docker-compose up -d`
- 環境變數：請向系統管理員索取 `.env` 範本。
